Foundations

Finite differences in one minute

Difference Table for $y = x^2$
$x$ $y = x^2$ $\Delta y$ $\Delta^2 y$ $\Delta^3 y$ $\Delta^4 y$
0 0 1
1 1 2
2 4 3 0
3 9 5 2 0
4 16 7 0
← Top edge: Forward formula Bottom edge: Backward formula →

Forward Difference ($\Delta$)

$\Delta y_r = y_{r+1} - y_r$

Backward Difference ($\nabla$)

$\nabla y_r = y_r - y_{r-1}$

Shift Operator ($E$)

$E \, y_r = y_{r+1}, \quad \text{so } \Delta = E - 1 \quad \text{and } \nabla = 1 - E^{-1}$

💡 Why it matters: $\Delta^2 y$ is constant ($=2$) and $\Delta^3 y = 0$, proving exact quadratic behavior without matrix inversions!
Newton-Gregory Interpolation — Experiential Learning Slide 5
Formulation

Newton-Gregory forward formula

The Forward Interpolation Polynomial
$$y(x) = y_0 + u\,\Delta y_0 + \frac{u(u-1)}{2!}\Delta^2 y_0 + \frac{u(u-1)(u-2)}{3!}\Delta^3 y_0 + \cdots + \frac{u(u-1)\cdots(u-n+1)}{n!}\Delta^n y_0$$
$$u = \frac{x - x_0}{h}$$ Use near the START of the table; $x_0$ is the first node and $h$ is uniform step size.
1

Assume a polynomial

y = a_0 + a_1(x-x_0) + a_2(x-x_0)(x-x_1) + \cdots

Factorial polynomials centered around sequential nodes.

2

Match the table

a_k = \frac{\Delta^k y_0}{k! \, h^k}

Each node point immediately computes one single additional difference.

3

Substitute $x = x_0 + uh$

(x-x_0) = uh, \; (x-x_1) = (u-1)h

Powers of $h^k$ cancel out directly into factorial factors.

Formulation & Decision Rule

Backward formula and which one to pick

The Backward Interpolation Polynomial
$$y(x) = y_n + u\,\nabla y_n + \frac{u(u+1)}{2!}\nabla^2 y_n + \frac{u(u+1)(u+2)}{3!}\nabla^3 y_n + \cdots + \frac{u(u+1)\cdots(u+n-1)}{n!}\nabla^n y_n$$
$$u = \frac{x - x_n}{h}$$ Use near the END of the table; $x_n$ is the last node and $u \le 0$.

Where is $x$ located in the table?

Near the start:

First half of table data $[x_0, x_1, \dots]$

FORWARD ($\Delta$)
Near the end:

Latter half of table data $[\dots, x_{n-1}, x_n]$

BACKWARD ($\nabla$)

Mirror Image Characteristics

  • Starts from the last point $y_n$
  • Uses values from the bottom edge of the difference pyramid
  • $u = (x - x_n)/h$ is typically negative ($\le 0$)
  • Middle of table: Central-difference formulas (Stirling/Bessel) do even better.

Error Analysis & Limits

How accurate is it? Know the limits

Noise gain of $\Delta^n$ ($\sigma$ of sensor noise)

Higher degree = Noise amplifies!
Truncation Error after $n+1$ points
$$R_n(x) = \frac{u(u-1)\cdots(u-n)}{(n+1)!} \, h^{n+1} f^{(n+1)}(\xi)$$

Small $u$, small step $h$, and a smooth function keep error bounded. Large higher derivatives blow it up!

Equal spacing required Unequal steps? Switch to Lagrange or Newton divided differences.
Interpolate, don't extrapolate Outside $[x_0, x_n]$ the error skyrockets rapidly (shown in Case 3).
⚠️ More terms ≠ always better: Stop when $\Delta^k$ is flat; high-order differences act like high-pass differentiators, severely amplifying sensor noise!

SIGNALS & SYSTEMS CONTEXT

Why Newton–Gregory in Signals & Systems?

Continuous to Discrete Transformation

When an analog signal $x(t)$ is sampled with period $T_s$, the samples $x[n] = x(nT_s)$ lie on a strictly uniform grid ($h = T_s$). Because step spacing is constant, finite differences eliminate the need for divided differences or matrix inverses.

1. Low CPU Complexity

Evaluates polynomial coefficients on hardware with simple accumulator multiply-adds instead of costly $\ln()$ or $\sin()$ calls.

2. Timing Recovery

Reconstructs fractional clock phase offsets $x[n + \mu]$ ($0 < \mu < 1$) in digital receivers without wide sinc FIR filters.

💡
System Guardrail: Newton–Gregory polynomials are ideal inside the sampled interval $[x_0, x_n]$. Extrapolating outside rapidly diverges into high-frequency error oscillations!
UNIFORM SAMPLING: X[N] = X(N·TS) Ts = 125 µs (8 kHz)

The Sensor Model Equations

$$\frac{1}{T} = \frac{1}{T_0} + \frac{1}{\beta}\ln\left(\frac{R_{NTC}}{R_0}\right)$$
$$\text{ADC} = 1023 \cdot \frac{R_{fixed}}{R_{NTC} + R_{fixed}}$$

Why interpolate instead of calculating formulas in MCU?

  • ln() and 64-bit float math consume hundreds of CPU cycles and battery power on low-cost MCUs.
  • Store just 5 points (ADC code, °C) in Flash memory instead.
  • Equal 100-count steps ($h=100$) → just one difference table needed!

Critical Thinking

Critical thinking: the extrapolation trap

Engineer's Temptation: Reuse the exact same polynomial for ADC < 300 and ADC > 700 to save table space. Does it work?

ADC code vs Extrapolation Error in °C

1. Does accuracy carry over outside?

No. Inside 300–700 error is $\le 0.014^\circ\text{C}$. But at ADC 900 error explodes to -5.3°C and at ADC 1000 by -50°C!

2. Why does it blow up?

The product term $u(u-1)\cdots(u-n)$ grows exponentially once $u$ strays outside $[0, n]$, and the physical device is logarithmic, not polynomial.

3. A safer design?

Extend the table to encompass full sensor operating bounds, and clamp/flag out-of-range sensor readings in firmware!

Software Implementation

Implementation in Python

newton_gregory_demo.py Python 3 
def diff_table(y):
    t = [list(y)]
    while len(t[-1]) > 1:
        p = t[-1]
        t.append([p[i+1] - p[i] for i in range(len(p)-1)])
    return t

def newton_forward(x0, h, y, x, deg=None):
    d = [row[0] for row in diff_table(y)]  # Δ^k y0
    u = (x - x0) / h
    s, term = d[0], 1.0
    for k in range(1, (deg or len(y)-1) + 1):
        term *= (u - (k - 1)) / k
        s += term * d[k]
    return s

Summary & Synthesis

Key takeaways

1

Differences are the engine

A difference table systematically turns discrete data into a polynomial: every extra term adds exactly one more finite difference without recalculating earlier coefficients.

2

Position picks the formula

Forward formula ($\Delta$) near the start, backward formula ($\nabla$) near the end. Strictly requires equal sample spacing $h$.

3

The ECE payoff

Five stored numbers give $\pm 0.014^\circ\text{C}$ over the full thermistor range (17× better than linear interpolation) and fractional DSP delay at $-56.6\text{ dB}$ residual error.

4

Know the limits

Interpolate, never extrapolate! Excessive degrees amplify sensor noise. Unequally spaced data requires Lagrange or divided differences.
